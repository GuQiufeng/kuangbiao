# 我的矿标 · 私人矿物馆版

这是一个本地优先的矿物标本收藏 PWA。日常只需要拍照、写矿物和产地；更复杂的收藏管理集中在“馆务”里。

## 日常记录
- 多图拍照 / 上传，原矿标与证书单独保存
- 主矿物、共生矿、收藏大类与细分类
- 科学矿物名、化学式、莫氏硬度、晶系、科学分类自动关联
- 知名产地快捷选择 + 国家 / 省州 / 市县 / 矿区自由输入
- 清洗、超声、酸洗、毒性、粉尘、避光、防潮等保守型养护提示；共生矿会一起参与判断
- 批量添加同矿物 / 同产地标本

## 私人矿物馆管理
- 自动馆藏编号 M-0001、M-0002……
- 柜位 / 收纳位置，位置改变自动写入时间线
- 矿物身份与产地可信度：确定 / 原标签 / 自己判断 / 待确认
- 照片时间线：入手、清洗、换柜位、损坏、修复、来源流转、借出归还、售出赠送
- 待办：待清洗、待拍照、待查产地、待补标签、待修复、准备出售
- 养护检查日期与到期汇总
- 借出与归还记录
- 愿望单：目标矿物、产地、预算、优先级、备注
- 相似 / 重复收藏提醒
- 尺寸自动粗分：Thumbnail / Miniature / Small Cabinet / Cabinet

## 收藏账本与流转
- 入手价、当前估值、准备售价、私密最低愿售价
- 收藏中 / 已售出 / 已赠送
- 损坏 / 修复状态独立保存
- 累计入手、回血、当前在藏成本、净现金投入
- “准备出售”清单，可导出漂亮 HTML 清单后打印 / 保存 PDF

## 统计与输出
- 矿物与产地排行
- 按年份查看新增、花费、回血、最常收的矿物和产地
- 导出年度回顾
- 单件导出博物馆式标本卡
- 单件导出馆藏标签；正式放到 HTTPS 地址后二维码可直接打开对应馆藏编号
- 知名产地示意分布图
- 完整 CSV 清单

## 数据与迁移
- 不需要账号
- 标本资料与照片存在当前浏览器 / PWA 的 IndexedDB
- 自定义分类和愿望单存在本机设置中
- “完整备份”会把标本、照片、时间线、分类和愿望单一起放入 `.mineralbackup`
- 换设备后导入即可恢复

## 预览
Windows 上可以直接双击 `直接双击打开_我的矿标.html` 看界面。正式长期使用仍建议放到 HTTPS 地址并“添加到主屏幕”，这样 PWA、本地数据库和二维码跳转更稳定。

## 关于二维码
本地 `file://` 预览时，二维码只能记录馆藏编号。等应用正式部署在 HTTPS 地址后，导出的二维码标签会自动改成该标本的页面链接。二维码图片生成时需要联网加载。

## 2026-08 矿物库系统复盘版
- 离线主矿物条目从 83 个扩充到 201 个，另有 500+ 名称/别名映射（中英文、常见商业名、部分繁体写法）。

- 菱锰矿：MnCO₃、三方晶系、莫氏 3.5–4；新增“红纹石”别名。
- 镜铁矿不作为独立矿物种存储，而归并到赤铁矿：Fe₂O₃、三方晶系、莫氏 5.5–6.5，并保留“镜铁矿 / Specularite”作为识别自名称。
- 大幅补充硫化物/硫盐、氧化物、卤化物、硼酸盐、碳酸盐、硫酸盐、磷酸盐/砷酸盐/钒酸盐、硅酸盐、沸石、石榴子石与电气石常见端元。
- 补充蛋白石、褐铁矿、硬锰矿等“非单一现代矿物种/准矿物”提示，避免系统把传统叫法硬塞进七大晶系。
- 清洗/安全库同步扩充：水溶盐、易氧化硫化物、光敏矿物、含铅/砷/汞/铀矿物、温石棉/毛沸石等纤维风险均使用更保守的提示。
- 知名产地新增广西梧桐矿（菱锰矿等）与湖北铜绿山矿（赤铁矿/镜铁矿等）。
- 新增真正的 PWA `manifest.json`、图标和 `sw.js`；导航采用网络优先更新策略，正式部署后更不容易长期卡在旧版本。

### 数据原则
这套内置库定位为“收藏常用离线库”，不是完整 IMA 全矿物数据库。科学名/别名和基础性质以现代矿物学数据库的主流写法为目标；遇到系列名、传统名、商业名会尽量明确提示，而不是伪装成独立矿物种。未收录名称仍可以照常保存并标记“待确认”。
